# Employee Management System with AI Assistant

A simple Employee Management System built using Node.js, Express.js, MongoDB and Handlebars.

I also integrated Google Gemini AI into the project, so users can ask questions about employee records and get answers directly from the application.

## Features

- Add, update and delete employees
- Employee details with profile photo
- Search and filter employees
- Employee ID generation
- Salary and employee statistics
- Export employee records to CSV
- AI Assistant using Google Gemini
- Suggested AI questions
- Ask custom questions about employee data
- Responsive Bootstrap UI

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- Handlebars
- Bootstrap
- JavaScript
- Google Gemini AI
- Multer
- Chart.js

## AI Assistant

The AI Assistant uses employee data stored in MongoDB to answer questions such as:

- How many employees are there?
- Who has the highest salary?
- What is the average salary?
- Show all Full Stack Developers.
- Which employees are from Delhi?

Users can also type their own questions.
